1. 수집하는 개인정보

'오늘 어디냥? (Where to, Meow?)'(이하 '사이트')는 회원가입, 댓글, 문의 양식 등을 운영하지 않으며 방문자의 이름·연락처 등 개인정보를 직접 수집하지 않습니다.

2. 쿠키 및 제3자 서비스

사이트는 다음 제3자 서비스를 이용할 수 있으며, 이들 서비스가 쿠키 등을 통해 정보를 처리할 수 있습니다.

  • GitHub Pages(호스팅): 접속 기록(IP 주소 등)이 보안 목적으로 처리될 수 있습니다.
  • Google AdSense(광고, 적용 시): Google 및 파트너는 쿠키를 사용해 방문 기록에 기반한 광고를 게재할 수 있습니다. 맞춤 광고는 Google 광고 설정에서 해제할 수 있습니다.
  • Google Fonts, Instagram 임베드: 글꼴·게시물 표시를 위해 해당 서비스에 접속 정보가 전달될 수 있습니다.
  • 제휴 링크(아고다, 마이리얼트립, 클룩, 쿠팡파트너스 등): 링크를 통해 이동하면 해당 업체 정책이 적용됩니다.

3. Google API 서비스 이용

사이트 운영자는 자신이 소유한 Blogger 블로그에 여행 가이드 글을 게시하기 위해서만 Google API(Blogger API)를 사용합니다. 이 과정에서 제3자 사용자의 Google 계정 정보에 접근하거나 이를 수집·저장·공유하지 않습니다. Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.
